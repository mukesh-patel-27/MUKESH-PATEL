# Mukesh Patel — Developer Portfolio

A responsive, dark developer portfolio with purple neon accents, built using plain HTML, CSS, and JavaScript. It is ready to publish with GitHub Pages.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

Optional: in VS Code, install/use Live Server and choose **Open with Live Server**.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository named `yourusername.github.io` (replace `yourusername` with your actual GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes. Your site should be available at `https://yourusername.github.io/`.

If you use a repository with another name instead, the URL is usually `https://yourusername.github.io/repository-name/`.

## Personalize before publishing

Edit `index.html`:
- Replace the GitHub and LinkedIn links with your real profile URLs.
- Replace `your.email@example.com` with the email address you want to publish.
- Update the skills section as your skills grow.
- Add links or screenshots for your projects when available.
- Confirm that the BloomLink demo link is still correct.

Edit `style.css` to change colors, spacing, typography, and layout.

## Files

- `index.html` — page content and sections
- `style.css` — responsive design and purple neon theme
- `script.js` — mobile navigation and current year
